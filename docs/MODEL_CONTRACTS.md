# Model contracts

_Generated by `node packages/contracts/scripts/write-docs.mjs` from `packages/contracts/src/chain.ts`. Do not edit by hand._

Every model in the mesh carries a contract (spec §2): typed inputs and outputs (quantity, unit, CRS, grid, time step, valid range), applicability, routing rules with the transform each hand-off needs, how uncertainty is carried, calibration status, the registry entries it reads, and its agent configuration. The validator in `packages/contracts/src/validate.ts` rejects any hand-off whose source output and target input do not match after the declared transform, and any hand-off the source contract does not declare. The JSON Schema is `packages/contracts/schema/model-contract.schema.json`.

A model is `signed_off` only when its calibration says so **and** every registry entry it depends on is `approved` (`gateStatus`). Only `signed_off` chains can produce results the studio shows; everything else stays admin-only.
